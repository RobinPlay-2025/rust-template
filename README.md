🧩 Шаблон плагина для игры Rust
> ⚠️ Для работы 🦀 rust-template нужен [Git](https://gitforwindows.org) 🔧
Готовый шаблон для разработки плагинов Rust.
Все необходимые библиотеки уже находятся в папке Managed ⚙️

🚀 Установка

Выберите среду разработки: Cursor, Windsurf или **Antigravity** 🧠

🛸 Antigravity AI

Самый мощный агентный ИИ для разработки плагинов Rust. 
*   **Скачать**: [antigravity.google](https://antigravity.google/releases?app=antigravity)
*   **Важно**: Регистрация доступна только через зарубежный Google-аккаунт.
*   **Автономность**: Сам исправляет ошибки, правит конфиги и создает файлы.
*   **Знание Rust**: Глубокое понимание Oxide и Carbon API.
*   **Скорость**: Реализация фич в один клик.

🖥️ Cursor

Скачайте с https://www.cursor.com/
Откройте Composer и выберите Agent mode 🤖
Установите и откройте проект

🌊 Windsurf

Скачайте с https://codeium.com/windsurf
Установите и откройте репозиторий

⚡ Быстрый старт

Клонируйте репозиторий:
```bash
git clone https://github.com/RobinPlay-2025/rust-template.git
```

Откройте проект в Cursor или Windsurf

Начните писать код! 💻🔥

🔄 Обновление и переключение фреймворка

Чтобы обновить библиотеки или переключиться между Oxide и Carbon без удаления своих плагинов:

1. Запустите `update.bat`.
2. Выберите нужный фреймворк (1 или 2).

🛠️ Автоматическая настройка IDE

Вам **не нужно** ничего переключать вручную! Скрипт `update.bat` сам настроит ваш редактор (Cursor/Windsurf) под выбранный фреймворк:
*   Автоматически переключит ссылки на библиотеки.
*   Настроит IntelliSense и подсказки под Oxide или Carbon.
*   Уберет ложные ошибки компиляции.

🚀 Скрипт сам скачает нужные файлы с GitHub и подготовит среду. Ваши плагины в папке `plugins/` останутся в полной безопасности.
