🧩 Шаблон плагина для игры Rust
> ⚠️ Для работы 🦀 rust-template нужен [Git](https://gitforwindows.org) 🔧
Готовый шаблон для разработки плагинов Rust.
Все необходимые библиотеки уже находятся в папке Managed ⚙️

🚀 Установка

Выберите среду разработки: Cursor или Windsurf 🧠

🖥️ Cursor

Скачайте с https://www.cursor.com/
Откройте Composer и выберите Agent mode 🤖
Установите и откройте проект

🌊 Windsurf

Скачайте с https://codeium.com/windsurf
Установите и откройте репозиторий

⚡ Быстрый старт

Клонируйте репозиторий:
```bash
git clone https://github.com/RobinPlay-2025/rust-template.git
```

Откройте проект в Cursor или Windsurf

Начните писать код! 💻🔥

🔄 Обновление шаблона и переключение фреймворка

Чтобы обновить библиотеки или переключиться между Oxide и Carbon без удаления своих плагинов:

*   **Для Oxide**: Запустите `update.bat -Framework Oxide`
*   **Для Carbon**: Запустите `update.bat -Framework Carbon`

🛠️ Смена режима в IDE

В нижней панели вашего редактора (Cursor/Windsurf) вы можете переключать конфигурацию сборки между `Oxide` и `Carbon`. Это автоматически изменит подсказки IntelliSense и ссылки на библиотеки.

🚀 Скрипт сам скачает нужные файлы с GitHub и настроит проект. Ваши плагины в папке `plugins/` останутся в безопасности.
